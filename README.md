# System Analysis and Design

A multi-project showcase of System Analysis and Design: each top-level project turns a business need into approved requirements, API specs, data models, diagrams, database migrations and tests, following Spec-Driven Development.

- `e-commerce/` is the current project: API specs in `doc/api`, schema docs in `doc/schema`, migrations and database tests in `db`, diagrams in `diagram`.
- `CLAUDE.md` and `AGENTS.md` are the entry points of the agents, `GLOSSARY.md` defines the repository terms, `.agents/` holds the shared rules, skills and templates.
- `docs/` holds the repository-wide documents and `tasks/` holds the plans and the lessons.
